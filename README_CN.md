# Surface Duo 折叠应用自适应演示

一个 Surface Duo 双屏设备的交互演示，展示设备在不同形态之间切换时，屏幕内的应用界面如何自动适应布局。无需安装、无需联网，用浏览器打开即可体验。

## 功能一览

### 三种设备形态

页面左侧提供三个按钮，点击后设备会以连贯的动画在形态之间过渡：

- **展开**：两块屏幕拼成一块完整大屏，应用以双屏布局铺满整个设备。
- **合上**：与展开相反，由大屏折回单屏。
- **外折**：右屏向后翻折，最终只保留一块屏幕显示。

页面打开时设备默认处于合上状态，点击按钮才开始播放动画。

### 屏幕内的示例应用

设备屏幕中运行着一个 UWP NavigationView 风格的示例应用：

- 左侧导航栏可在首页、搜索、账户、邮件、设置等栏目间切换。
- 中间为文章列表，右侧为文章详情，点击列表项可查看对应内容。
- 点击左上角菜单按钮可展开/收起导航栏。
- 支持明色、暗色两种外观风格。
- 展开为双屏时，列表与详情自动分到左右两块屏幕；折成单屏时自动变为单列页面，并可在列表与详情之间前后切换。
- 在一块屏幕上操作（切换栏目、选择文章、展开菜单）时，另一块屏幕的内容会同步更新。

### 界面与观感

- 左上角显示标题，左侧为操作按钮栏。
- 应用背景采用柔和的多色渐变。
- 设备与应用始终铺满屏幕区域，不会出现内容溢出或留白错位。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 演示主页面，包含标题、操作按钮和设备画面 |
| `surface duo open.html` | 设备展开 / 合上形态的演示页 |
| `surface duo out fold.html` | 设备外折形态的演示页 |
| `navigateviewer.html` | 运行在设备屏幕中的示例应用 |

## 如何打开

由于页面以嵌入方式加载，建议通过本地静态服务器访问：

```bash
python -m http.server 8000
```

然后在浏览器中打开 `http://localhost:8000/index.html`。建议使用最新版 Edge 或 Chrome 浏览器。
